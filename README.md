## What I’m building with LoopFold

[LoopFold](https://loopfold.co) is a one-person studio offering AI setup, workflow automation, and coaching for owner-run small businesses. The focus is the work that falls between tools: missed inquiries, bookings, quotes, invoices, follow-up, and organized business records.

The approach is to understand the existing workflow, configure a useful system in the owner’s accounts, test the connections, document it, and teach the owner to run it. Ownership and a clear handover are part of the product.

## How I work

1. Understand the real task and the people doing it.
2. Map the inputs, decisions, handoffs, and failure points.
3. Build a focused working version; keep the setup understandable.
4. Verify actual behavior and state changes, including reset and recovery.
5. Document decisions, alternatives, tradeoffs, evidence, and remaining limits.

The project READMEs and `docs/DESIGN-DECISIONS.md` files explain those choices. I distinguish original workflow design from AI-assisted implementation, prototypes from released tools, and observed results from intended benefits.
